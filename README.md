# Rabia Tabbassam — Developer Portfolio

A responsive, dark-themed personal portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Preview

The website introduces Rabia Tabbassam, her education, growing technical toolkit, selected learning projects, and professional links.

## Tech stack

- HTML5
- CSS3 (responsive layouts, gradients, reduced-motion support)
- Vanilla JavaScript
- Google Fonts (Manrope and DM Mono)

## Run locally

No package installation or build step is required.

1. Clone this repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Edit the content in `index.html` and visual styles in `styles.css`.

## Deploy to Vercel

1. Import this GitHub repository into Vercel.
2. Select **Other** as the framework preset if prompted.
3. Set the project root to `.`.
4. Leave the build command empty.
5. Leave the output directory at its default/empty setting.
6. Deploy.

The site is static and currently requires no environment variables.
